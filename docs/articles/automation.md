# 構築自動化とトラブルシューティング自動化

ラボの構築や、障害試験・トラブルシューティングの自動化に向けて参考にしている記事です。

## Claude Code に CML 2.10 を操作させてネットワークを構築

- リンク: [note（61び 氏）](https://note.com/61bi_234469/n/n94c0813006e6)
- 公開: 2026年9月
- 使っているもの: Claude Code、CML 2.10 の MCP Server

CML 2.10 の MCP Server を Claude Code につなぎ、AI エージェントにネットワーク構築を任せた検証記事。要件を伝えるだけで、3台のルータで OSPF と BGP を相互再配送する構成をほぼ一度で組み上げ、経路も想定どおりだったとしている。

要件定義・構成図の作成から構築、障害時の切り分けまで段階的に試していて、切り分けまではできたが完全な解決には届かなかったという結果も書かれている。個人ラボや資格学習には十分使える一方、大規模で複雑な環境には課題が残るという評価。

**参考にしたい点**

- 構築の自動化：要件から構成・コンフィグまでを AI に組ませる流れ
- トラブルシューティングの自動化：障害を入れて切り分けさせる進め方と、その限界
