# 2026-11-22 2960X のパスワードリカバリと、自宅ラボの SW1 の設置

## 今日やったこと

- 2960X のユーザ名とパスワードを忘れて入れなくなったので、**MODE ボタンでパスワードリカバリ**をした（設定は残したまま）
- Buffalo ルータの下に 2960X（SW1）を置き、Z8 G4（CML）とサーバ用 PC をつないだ
- SW1 に管理用の IP を設定し、ルータと CML への疎通を確認した
- CML につながらない問題に当たった。原因は **Z8 の LAN ポートの挿し間違い**だった

構成図と VLAN の計画は [自宅ラボ構築ログ](../homelab/index.md) にまとめている。

## 2960X のパスワードリカバリ

コンソールケーブル（9600bps、8N1）でつないで作業した。

1. 電源ケーブルを抜く
2. 前面の **MODE ボタンを押したまま**電源ケーブルを挿す
3. `switch:` が出るまで押し続ける

```text
switch: flash_init
Initializing Flash...
...The flash is already initialized.

switch: dir flash:
switch: rename flash:config.text flash:config.text.old
switch: boot
```

起動したら初期設定のダイアログには `no` と答え、元の設定を戻してからパスワードだけ変える。

```text
Switch> enable
Switch# rename flash:config.text.old flash:config.text
Switch# copy flash:config.text system:running-config
SW1# configure terminal
SW1(config)# username <ユーザ名> privilege 15 secret <新しいパスワード>
SW1(config)# enable secret <新しいパスワード>
SW1(config)# end
SW1# write memory
```

!!! warning "つまずいたところ"
    - ボタンを離すのが早いと普通に起動してしまう。**電源を挿す前から押し始めて、`switch:` が出るまで押し続ける**と確実だった
    - ブートローダーでは `flash:` までが1つの名前。コロンを忘れるとエラーになる

    ```text
    switch: dir flash
    unable to stat flash/: no such device
    ```

## SW1 の設定

ルータ向けのポートは access にした。Buffalo（家庭用のモデル）はタグ VLAN を扱えないので、trunk にする意味がない。

```text
interface GigabitEthernet1/0/1
 switchport mode access
 switchport access vlan 1
!
interface GigabitEthernet1/0/3
 description from_SW1_to_Z8-G4
 switchport mode access
 switchport access vlan 1
 spanning-tree portfast
!
interface Vlan1
 ip address 192.168.11.250 255.255.255.0
```

```text
SW1#show interfaces status
Port      Name               Status       Vlan       Duplex  Speed Type
Gi1/0/1                      connected    1          a-full a-1000 10/100/1000BaseTX
Gi1/0/2                      notconnect   1            auto   auto 10/100/1000BaseTX
Gi1/0/3   from_SW1_to_Z8-G4  connected    1          a-full a-1000 10/100/1000BaseTX
```

Gi1/0/2 はサーバ用 PC の電源が入っていないので `notconnect` で正常。`Gi1/0/3` は最初 `disabled`（shutdown されていた）だったので `no shutdown` で有効にした。

## わかったこと

- スイッチから ping を打つには、スイッチ自身に IP が要る（`interface vlan 1` に IP を振り、`no shutdown`）。PC 同士の通信だけなら、L2 スイッチに IP はいらない
- **リンクが上がっていても、相手が正しいとは限らない**。下の層から順に確かめると原因にたどり着ける（[リンクは上がっているのに通信できないとき](../troubleshooting/link-up-wrong-nic.md)）
- 入力中にログが割り込んでコマンドが崩れるので、`line console 0` に `logging synchronous` を入れておくと楽
